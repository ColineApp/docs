Apps add capabilities to a workspace: tools for Kairo, commands in search, file types with their own previews and editors, and their own home screens. An app's files live in its own drive in [Drive](/drive).

## The App Store

Open **Apps** to browse curated collections and categories, and search listings with screenshots, descriptions, version history and developer details. Public store pages are at [coline.app/store](https://coline.app/store).

## Installing

Before you install, you see exactly what the app can do: the permissions it asks for, the outside services it can reach, and the tools it adds. Depending on your workspace's app policy, you may need an admin to install it.

Once installed, an app's tools are available to Kairo, to [crew members](/kairo/crew), and to external agents through the [MCP server](/api/mcp). Kairo asks before running tools that delete things or reach outside Coline, depending on your [permission mode](/kairo/overview#permission-modes).

## Updates

- Updates that ask for no new access install automatically if your workspace allows it.
- An update that asks for more access waits for an admin to approve it.
- Admins can roll back to any approved version.

## Private apps

Teams can build apps that only their workspace can see and install, or share an app through an unlisted install link. To build one, see the [app SDK](/sdk).

## App policies

In **Settings → Apps**, admins decide who can install apps, allow only specific apps, and block permissions. Installs that break a policy are paused, with an explanation.

## Uninstalling

Uninstalling keeps an app's data for 30 days in case you reinstall. You can also delete it immediately.

## Paid apps
