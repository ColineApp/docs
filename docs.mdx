Docs is for writing that needs structure and layout: reports, proposals, specs and letters. For quick, linked notes, use [Notes](/notes).

## The editor

The toolbar is split into tabs:

| Tab | Has |
| --- | --- |
| **Home** | Undo and redo, paragraph styles, font, size and weight, bold, italic and other formatting, colors and highlights, alignment, lists and indentation |
| **Insert** | Images (from Drive, your computer or a URL), YouTube videos, tables, dividers and page breaks |
| **Format** | Line spacing, text direction, callout colors and clearing formatting |
| **Table** | Appears in a table: insert and delete rows and columns, merge cells, cell colors, and distribute rows and columns evenly |
| **Page** | Margins (normal, narrow, wide), orientation, page color and page numbers |
| **View** | Paged or continuous layout, fit width, zoom, focus mode, ruler and the stats bar |
| **Review** | Spell check and document stats |

Paragraph styles include title, three heading levels, quote, pull quote, callout, caption, footnote and code block. Headings build the document outline.

Press `⌘Enter` to insert a page break.

## Writing with Kairo

Ask Kairo to draft, rewrite or continue from inside the document. [Tab](/api/tab) suggests the rest of your sentence as ghost text.

## Collaboration

- Edit together in real time and see who's in the document.
- The save status shows when your work is saved. If your connection drops, Docs keeps a draft and recovers it, so you never lose what you wrote.

## Word files

Open `.docx` files from Drive in Docs, or upload them from the Docs home. Search your Word documents from the Docs home too.

## Sharing and printing

Share a doc like any file; see [Drive](/drive#sharing). The print button is in the document header.

## The Docs home

The Docs home lists your documents with filters and search. Opening one animates into the editor.
