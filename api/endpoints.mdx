---
title: Endpoint reference
description: Every Coline API route, with the scope it needs.
---

Paths are relative to `https://coline.app/api/v1`. Request and response schemas are in the [OpenAPI description](https://coline.app/api/v1/openapi/app-platform), and the developer portal has an [interactive reference](https://coline.app/developers/api-reference).

**OAuth** means the route acts for a person and needs an [OAuth token](/authentication/oauth); workspace API keys get `403 USER_IDENTITY_REQUIRED`. Every other route accepts both. Routes marked † work today but aren't in the OpenAPI description yet.

## Identity

| Method | Path | Does | Scope |
| --- | --- | --- | --- |
| `GET` | `/me/workspaces` | List the person's workspaces | `workspace.read` (OAuth) |
| `GET` | `/workspaces/{workspaceSlug}/members` † | List workspace members | `workspace.read` |
| `GET` | `/oauth/userinfo` | The signed-in person | OAuth token |

## Messages

Messages act for a person: you can read and post only in conversations that person is in, exactly as in the app. With an API key, only the public channel list is available.

| Method | Path | Does | Scope |
| --- | --- | --- | --- |
| `GET` | `/workspaces/{workspaceSlug}/channels` † | List public channels, plus private channels the person is in | `workspace.read` |
| `GET` `POST` | `/workspaces/{workspaceSlug}/channels/{channelId}/messages` † | Read or post channel messages | `workspace.read` / `messages.write` (OAuth) |
| `GET` | `/workspaces/{workspaceSlug}/dms` † | List the person's DMs | `workspace.read` (OAuth) |
| `GET` `POST` | `/workspaces/{workspaceSlug}/dms/{dmId}/messages` † | Read or post DM messages | `workspace.read` / `messages.write` (OAuth) |
| `GET` | `/workspaces/{workspaceSlug}/messages/{messageId}` † | Get a message | `workspace.read` (OAuth) |
| `PATCH` `DELETE` | `/workspaces/{workspaceSlug}/messages/{messageId}` † | Edit or delete your own message | `messages.write` (OAuth) |
| `GET` `POST` | `/workspaces/{workspaceSlug}/messages/{messageId}/thread` † | Read a thread, or reply in it | `workspace.read` / `messages.write` (OAuth) |
| `PUT` `DELETE` | `/workspaces/{workspaceSlug}/messages/{messageId}/pin` † | Pin or unpin a message | `messages.write` (OAuth) |
| `PUT` `DELETE` | `/workspaces/{workspaceSlug}/messages/{messageId}/reactions/{emoji}` † | Add or remove your reaction | `messages.write` (OAuth) |

Messages you post appear under the person's name. Posting into a conversation the person isn't in fails with `403`.
