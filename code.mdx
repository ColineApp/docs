Code is Coline's IDE and agent workspace. Open a repository, edit it yourself, or put coding agents to work on it, in the cloud or on your Mac.

## Projects

- **Cloud projects** run on a Code computer in the cloud. Create one from an [Upstream](/upstream) or GitHub repository, or create a new repository with the project. Existing GitHub repositories can be moved to Upstream.
- **Local projects** open folders on your Mac in [Coline Desktop](/getting-started#desktop-app) and run agents against them locally. Recent folders are under **File → Open Recent**.
- **Coline App** projects scaffold an [app](/sdk/publishing#build-in-coline-code) that an agent builds with you.

Local and cloud projects appear together on the Code dashboard. Agent tabs and sessions are restored when you come back.

## The editor

- A file explorer, tabs, search, syntax highlighting and notebook support.
- A terminal and source control with live progress for every Git operation.
- Inline Kairo: select code and ask for an edit in place.
- [Tab](/api/tab) code completions as you type.
- Bring your own AI provider in the editor settings if you prefer.

## Agents

Start an agent from the project's agent composer and describe the work. Agents run on the project's Code computer, so they keep going when you close the tab.

- Check **worktree** to give an agent its own copy of the repository, so several agents can work in parallel.
- Watch an agent's edits appear live in the review panel, with an inline diff.
- Review any commit file by file.
- When the work is ready, open a Change Request on Upstream or a pull request on GitHub. It links back to the task, the session and any evidence such as previews and screenshots.
- Per-project agent settings set defaults for every agent in the project.
- The team view shows recent coding activity across the workspace.

Kairo and [crew members](/kairo/crew) hand repository work to Code: they start a Code session with the task written as instructions, and report back with what it found.

## Code computers and credits

Code computers start almost instantly. They're paid for with Code credits, which come with paid plans; see [plans](/plans). Workspace admins can see usage in **Settings → Code credits**.

## Sync

Projects sync across devices, and sync handles diverged branches.
