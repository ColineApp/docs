Coline is a workspace for teams. Messages, mail, calendar, files, docs, sheets, notes, tasks and code live in one app, under one account and one set of permissions. Kairo, Coline's agent, works across all of it: it answers questions about your work, drafts and edits, runs routines on a schedule, and can join your team as named crew members who take on work of their own.

Coline runs in the browser at [coline.app](https://coline.app) and as a desktop app for macOS. Upstream, Coline's Git forge, is part of every workspace and is also available on its own at [upstream.codes](https://upstream.codes).

## What's in a workspace

| Area | What it's for |
| --- | --- |
| [Home](/home) | Your day: what's next, what's in motion, and what's waiting on you |
| [Inbox](/inbox) | Notifications, messages and mail in one list |
| [Messages](/messages) | Channels, DMs and threads, with calls, clips and agents |
| [Mail](/mail) | Every connected inbox, with fast triage and shared inboxes |
| [Calendar](/calendar) | Native calendars, Google Calendar sync, scheduling links and meetings |
| [Drive](/drive) | Every file in the workspace, with sharing and previews |
| [Docs](/docs), [Sheets](/sheets), [Notes](/notes) | Writing, structured data and knowledge |
| [Tasks](/tasks) | Boards, lists and timelines |
| [Code](/code) | Cloud and local projects with coding agents |
| [Upstream](/upstream) | Repositories, Change Requests, issues and checks |
| [Apps](/apps) | Reviewed apps from the Coline App Store, or your own |

## For agents and developers

Every page of these docs is available as Markdown: add `.md` to its URL, or request it with `Accept: text/markdown`. [`/llms.txt`](https://docs.coline.app/llms.txt) lists every page, and [`/llms-full.txt`](https://docs.coline.app/llms-full.txt) has the full text.

- **Connect an agent:** the hosted [MCP server](/api/mcp) at `https://mcp.coline.app/mcp` signs in with OAuth and works with your existing permissions.
- **Call the API:** the [REST API](/api) uses workspace API keys or OAuth tokens. The OpenAPI description is at `https://coline.app/api/v1/openapi/app-platform`.
- **Build an app:** the [app SDK](/sdk) adds tools, file types and screens to a workspace. Kairo can use an app's tools as soon as it's installed.
