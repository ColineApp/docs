Notes is a block editor for knowledge that grows over time: team wikis, meeting notes, project briefs and journals. Pages nest inside each other and link to each other. For formal, page-laid-out documents, use [Docs](/docs).

## Writing

- Type `/` to insert any block: headings, lists, to-dos, toggles, quotes, callouts, code, tables, images, files, embeds and more.
- Select text to format it or **turn it into** another block type.
- Mention people, dates, pages and tasks inline. Task mentions are real Coline tasks.
- Add a cover image and an icon to any page.
- [Tab](/api/tab) suggests the rest of your sentence as ghost text.

## Pages and structure

- Pages can have **subpages**. The sidebar shows a page tree with inline rename, sorting, collapse all, and drag to move or un-nest.
- **Page properties** add structured fields to a page.
- **Page links and backlinks** connect related pages. Each page shows what links to it.
- **Synced sections** stay the same everywhere they appear. Edit one, and every copy updates.
- `⌘N` creates a page and `⌘F` searches.

## Starters

Start a page from a starter such as meeting notes, a journal or a project brief. Turn on daily notes to get a page for each day.

## Kairo in Notes

- The page assistant answers questions about the page and edits it on request.
- Page tools summarize, extract action items and tidy up.

## Collaboration

- Edit together in real time.
- **Comments** on pages and on selections, with replies and resolve.
- **Version history** for every page. Restore any earlier version.
- Your typing is never overwritten by autosave or sync.

## Sharing and publishing

Share a page with people, set link access, or publish it to the web as a clean, readable page with an optional password. See [Drive](/drive#sharing).

## Import

Import Markdown files or a Notion export. You see a preview before anything is imported. Notion databases become typed [Sheets](/sheets).
