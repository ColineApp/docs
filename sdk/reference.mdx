## Permissions

Declared in the manifest, approved by a workspace admin at install, and shown to people with exactly this wording. Every capability call needs its permission declared and granted.

| Permission | Shown to people as |
| --- | --- |
| `references.read` | Resolve names and links for workspace objects you can access. |
| `tasks.read` | Read tasks and task board statuses you can access. |
| `tasks.write` | Create, edit, and delete tasks on your behalf. |
| `calendar.read` | Read calendar events you can access. |
| `calendar.write` | Create, edit, and cancel calendar events on your behalf. |
| `messages.read` | Read conversations and task or event comments you can access. |
| `messages.write` | Send messages and comments on your behalf. |
| `members.read` | See who is in the workspace (names, emails, handles, avatars). |
| `files.read` | Read files the installing user can access. |
| `files.write` | Create and update files on behalf of users. |
| `drives.app` | Use its own app drive for files it creates. |
| `storage.app` | Store app data (key-value state and records) in the workspace. |
| `search.index` | Add its content to workspace search. |
| `search.query` | Search the workspace on behalf of users. |
| `notifications.write` | Send notifications to workspace members. |
| `ai.generate` | Use Coline AI models (billed to the workspace). |
| `ai.tools` | Offer tools that Kairo and agents can run. |

| `webhooks.subscribe` | Receive workspace events at its backend. |
| `commands.register` | Add commands to the command palette. |
| `realtime.subscribe` | Receive live updates for its own surfaces. |
| `network.external` | Call the external services it lists (through Coline, with the app's own credentials). |

| `endpoints.receive` | Receive requests from the external services it lists at private URLs. |

| `site.serve` | Serve a public website. Visitors can use only the tools and collections the app opens to them. |

## Tool effects

An effect isn't a label. The runtime enforces it as a ceiling on what a tool's code can do, on both sides of the trust boundary.

| Effect | Means |
| --- | --- |
| `read` | Reads workspace data. Kairo runs these without asking |
| `write` | Creates or updates data. Whether Kairo asks first depends on the person's [permission mode](/kairo/overview#permission-modes) |
| `destructive` | Deletes or irreversibly changes data. Kairo asks first unless the person chose Full access |
| `external` | Causes effects outside Coline, such as email or calls to external APIs. Kairo asks first unless the person chose Full access |

## Site visitors

A [site](/sites) page can call only these operations, and only on collections whose rules let the visitor: `storage.records.count`, `storage.records.delete`, `storage.records.get`, `storage.records.insert`, `storage.records.query`, `storage.records.sync` and `storage.records.update`. Everything else fails with `unavailable_to_visitors`; do it in a site tool.

## Chat cards

Tool result cards and inline file surfaces render inside conversations, so they accept this subset of tree nodes. Home, preview and editor surfaces can use every node.

`Alert`, `Avatar`, `Badge`, `Button`, `Card`, `Chart`, `CodeBlock`, `Divider`, `FileCard`, `Heading`, `Image`, `KeyValue`, `Link`, `List`, `Progress`, `Reference`, `Stack`, `Stat`, `Table`, `Text`, `UserChip`

## Runtime limits

Generous by default, and every limit fails closed with a named error that the execution log shows.

| Limit | Value |
| --- | --- |
| Capability calls | 120 burst, refilling 20 per second, per install |
| `net.fetch` | 20 burst, refilling 2 per second, per install |
| `ai.generate` | 200 calls per install per day |
| Executions | 10,000 per install per day (tools, renders and schedules) |
| Logic bundle | 5 MB |
| Client bundle | 8 MB |
| Storage | 5,000 key-value keys, 200,000 records per collection, 200 kB per value |
| Realtime events | 32 kB per event payload |
| Background job attempt | Up to 15 minutes |
| Site traffic | Counted per site, not against executions; see [Sites limits](/sites/limits) |
