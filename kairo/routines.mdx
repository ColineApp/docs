---
title: Routines
description: Standing work that an agent does on a schedule or when something happens.
---

A routine is a job you set up once with an agent, like "post a summary of the week's shipped work in #team every Friday at 4 PM" or "when a new post lands in #support, tag the right team". Kairo or a [crew member](/kairo/crew) runs it each time.

## Set one up

Ask in any conversation: describe what you want, when, and where results should go. The agent sets up the routine and confirms it in one line. Results post in the thread where you set it up unless you say otherwise.

## Schedules

| Runs | |
| --- | --- |
| **Every day** | At a time you choose |
| **On certain days** | Such as Mondays and Fridays |
| **Monthly** | On a day of the month |
| **Custom** | Any schedule |
| **When something happens** | After an event, such as a new message in a channel |

Times use your time zone. Each run posts a short line, with the work in a thread under it.

## Manage routines

Your routines are in Kairo → Customize → **Routines**, and a crew member's are on its profile. For each routine you can:

- edit its name, instructions, schedule and where it posts
- run it now as a test
- pause, resume or delete it
- see each run and whether it finished or failed

A routine pauses itself after 3 failures in a row, or when its agent is paused, and tells you why.

## Goals or routines?

Use a routine for the same work at a set time. For work toward an outcome, or watching for something until it happens, ask for a goal instead; see [goals](/kairo/crew#goals).
