Kairo is the agent built into Coline. It can read everything you can open in your workspace, and act in it on your behalf: drafting, editing, searching, scheduling, filing tasks, running code and working on the web. It never sees anything you can't.

## Where to find it

| | |
| --- | --- |
| **Kairo page** | Full conversations, with history, search and attachments |
| **Kairo sidebar** (`⌘.`) | A side panel next to whatever you're working on |
| **Search** (`⌘K`) | Ask a quick question from the command bar |
| **Quick dialog** (`⇧⌘K`) | A floating Kairo from anywhere |
| **`@kairo` in conversations** | Ask about a channel, DM or thread |
| **In editors** | Draft and rewrite in Docs, Notes, Mail and Code |

## It knows what you're looking at

The sidebar, `⌘K` and the quick dialog send what you have open and selected with each message: the email, doc, note, sheet, task, event, file or code you're on, and your selection. A **Looking at** chip shows what's included; dismiss it to leave it out. On the Kairo page, use **Attach what's open** in the `+` menu. Turn this off in Preferences.

## What it can do

- **Your workspace:** search and read files, messages, mail, tasks, calendar and code. Create and edit docs, sheets, notes and tasks; draft and send mail and messages; schedule events; work with repositories and Change Requests. Installed [apps](/apps) add their own tools.
- **The web:** search the web and read any page you point it to. Sources show as chips, and answers cite them inline.
- **Visuals:** Kairo draws charts, tables and interactive views in its replies when they help, and updates them as it writes. Copy them as images, export PNG, HTML or CSV, or share a public link. Mermaid diagrams and math render too.
- **Code:** run sandboxed JavaScript to compute, parse or check something, or hand repository work to [Code](/code).
- **A computer:** start a cloud computer with a browser, terminal and desktop for work that needs one. See [Kairo's computer](/kairo/computer).
- **Memory:** remember decisions, preferences and how your team works. See [memory](/kairo/memory).

## Permission modes

Choose how much Kairo may do without asking, from the composer:

| Mode | Kairo |
| --- | --- |
| **Default** | Reads and edits your workspace freely. Asks before sending, deleting, sharing, buying, or running commands |
| **Auto** | A quick check reviews risky actions and asks only when something looks off or wasn't requested |
| **Full access** | Does everything without asking |

Signing in to a website always comes back to you, since you have the password.

## Models and reasoning

Pick a model from the model picker, a searchable list. The reasoning control next to it sets how hard Kairo thinks; higher levels take longer and use more credits. Supported models also have **Pro** mode for the hardest work. See [plans and credits](/plans#credits).

## Conversations

- The Kairo sidebar lists conversations, with replies still in progress in their own section. Rename, link or delete any conversation.
- Hand a conversation to a [crew member](/kairo/crew) when the work should keep going without you. Kairo starts it as their goal and links it in the chat.
- Type `/` in the composer for commands and [skills](/kairo/customize#skills).

## Kairo in a team

In a team workspace, Kairo is a member you can DM and mention. It answers in shared conversations using only what's in that conversation and what everyone there can see. For agents with their own job, see [Kairo Crew](/kairo/crew).
